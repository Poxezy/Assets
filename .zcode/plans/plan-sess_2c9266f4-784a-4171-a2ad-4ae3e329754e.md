## Masalah
`book (1) Variant` / book KnowledgeItem **hilang saat Play** (semua scene).

## Root cause
1. **Semua book share `itemId: book_classroom_01`**  
   Prefab `book (1) Variant.prefab` + classroom books + 4 instance campusyard.
2. **`KnowledgeItem.Start` hide kalau prefs sudah 1**  
   Key: `KnowledgeItem_book_classroom_01_Collected`  
   Ambil 1 book → next Play **semua** book `SetActive(false)`.
3. **Reset progress tak clear key book**  
   Score/badge reset, key collect book tetap.
4. **Trigger prefab terlalu kecil** (~0.12×0.46×0.3)  
   `EnsureTrigger` skip kalau trigger sudah ada → susah di-pickup (gejala sekunder).

Alur: scene place book → Play → prefs clean = aktif + spin/light → Player tag enter trigger → +50 → prefs=1 → Destroy → next Play hide semua id sama.

## Fix (minimal)

### 1. `KnowledgeItem.cs` — ID stabil unik per object
Di `Awake`/`Start` (sebelum cek prefs):
- Jika `itemId` kosong **atau** default `book_classroom_01`, set:
  `{sceneName}_{sanitizedGameObjectName}`
- Contoh: `campusyard_book__1__Variant__2`, `classroom_book__3`
- Nama instance di scene sudah beda → key prefs beda → 1 book tak bunuh semua.

Opsional kecil: public static clear helper / method `ClearAllCollectionPrefs` scan `PlayerPrefs` sulit (Unity tak list keys) → clear lewat daftar prefix di reset (lihat #3).

### 2. `KnowledgeItem.EnsureTrigger` — perbesar trigger kecil
Kalau trigger sudah ada tapi size max axis &lt; ~0.8 (local, setelah scale approx), **resize** box ke min ~1×1×1 (atau fit renderer bounds seperti bootstrap). Jangan biarkan collider 0.1-an.

### 3. Reset progress clear book collect
Di `ScoreManager.ResetProgress` (dan/atau `SaveLoadManager.ResetProgress` kalau itu entry reset UI):
- Hapus known keys **atau** lebih rapi: simpan list collected IDs di 1 string prefs (`CollectedKnowledgeItems`) yang di-clear total — **pilih path terpendek**:
  - **Path A (paling pendek):** ganti storage ke satu key list; reset = hapus 1 key.
  - **Path B:** tetap per-item key; di reset hardcode clear default + document `PlayerPrefs.DeleteAll` / editor clear.

**Rekomendasi lazy:** Path A di `KnowledgeItem`:
- `PlayerPrefs` string `KnowledgeCollected` = comma-separated ids  
- `collectOnlyOnce` cek `Contains(id)`  
- Reset: `PlayerPrefs.DeleteKey("KnowledgeCollected")`  
- Sekalian migrate: abaikan key lama `KnowledgeItem_*` (user clear sekali via DeleteAll atau ignore).

### 4. Prefab `book (1) Variant.prefab`
- Perbesar `BoxCollider` trigger (min ~1,1,1 local atau fit mesh).
- `itemId` boleh default; runtime #1 override ke unik. Atau biarkan default, andalkan #1.

### 5. Scene overrides (opsional, kalau #1 cukup skip)
- classroom: 3 book id unik manual — **skip** jika auto-id dari nama cukup.
- campusyard: instance sudah bernama beda — auto-id cukup.

### 6. Verifikasi manual (setelah apply)
1. Edit → Clear All PlayerPrefs (sekali, bersihkan state lama).
2. Play `campusyard` + `classroom`: book aktif di Hierarchy.
3. Ambil 1 book → score +50, book hilang.
4. Stop + Play lagi: book lain **tetap** ada; book sudah diambil hilang.
5. Reset progress: book yang diambil muncul lagi.
